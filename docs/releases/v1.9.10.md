# bstrings v1.9.10 - Windows x64

This release simplifies the complete offline kit to one Full quality profile,
adds measured OCR/recovery percentages, and records the document-reading
architecture and benchmark roadmap.

## One Full profile

The release publishes only the accepted `quality` profile using Hy-MT2 7B
Q8_0. The former 1.8B balanced/compact installation choices are retired. The
installer, split-pack acquisition, trust manifests, acceptance evidence, and
release asset gate now share the same single-profile contract.

This removes a user-facing quality/size decision while retaining explicit,
hash-pinned profile identity in manifests and reports.

## Visible progress

Offline OCR and Magika/FLOSS recovery now report completed inventory files from
0% to 100%. Their child percentages feed the existing `Progress: analysis:`
display, alongside native extraction, translation, installer, acquisition,
hashing, assembly, and verification progress. Percentages are completed work
units, not time estimates.

## Document-reading decision

The reviewed design remains native-text first, coordinate-preserving OCR second,
and generative document/VLM output only as separately labelled supplemental
evidence after benchmark acceptance. Current public VLM benchmarks do not yet
establish the exact-token recall, hallucination limits, determinism, provenance,
Windows offline closure, or end-to-end performance needed to replace the
canonical PP-OCRv6 path.

See the [document-reading research and roadmap](../document-reading-research-2026-08.md)
for the Microsoft, Google, OpenAI, PaddlePaddle/Hugging Face comparison and the
next coverage, reconciliation, layout, and bounded-pipeline work.

## Install the complete kit

Use the checksum-verifying bootstrap in the
[v1.9.10 README](https://github.com/Donovoi/bstrings/blob/v1.9.10/README.md#get-started).
It authenticates and runs `Install-BstringsQuality.ps1`.
It assembles and verifies one offline directory containing native CPU/Rust/
CUDA-hybrid extraction, Magika, FLOSS, OCR, language detection, local
translation, all built-in patterns, TSV reports, and histograms.

```powershell
.\bstrings-quality\bstrings.exe bundle verify
.\bstrings-quality\bstrings.exe help analyze
.\bstrings-quality\bstrings.exe analyze -f "C:\evidence\memory.raw" --full -o "C:\results\memory-full"
```

The result directory must be new or empty. The installer bootstrap safely
replaces an existing physical installer only after authenticating the new
published digest.
