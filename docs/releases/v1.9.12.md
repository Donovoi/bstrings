# bstrings v1.9.12 - Windows x64

v1.9.12 is the complete Windows x64 quality/offline release. It fixes upgrades
over an existing `bstrings-quality` directory while retaining the single Full
profile, early fail-open content routing, provenance, reports, and percentage
progress introduced in v1.9.11.

## What changed

- every installer run now assembles the authenticated release into a unique
  physical sibling staging directory instead of treating an existing
  destination as an idempotency check;
- the staged kit must match the release trust manifest and pass `bundle verify`
  through the authenticated core before any existing installation is changed;
- an existing physical `bstrings-quality` directory is moved to a unique sibling
  backup, the verified replacement is moved into its exact destination, and a
  second verification runs through the newly installed executable;
- a failed publication or installed-path verification restores the complete
  previous directory instead of leaving a mixed-version kit;
- stale and unrelated files from the previous destination are removed with the
  replaced directory rather than copied into the new release;
- linked or reparse-point installation trees remain rejected so replacement and
  cleanup cannot cross the selected destination boundary; and
- installer progress now identifies staging, staged verification, publication,
  and final installed verification while the bundle client continues to report
  measured download, hashing, assembly, and verification percentages.

The default cache is still version-scoped and removed after success. A failed
run retains its authenticated resumable cache, but a later successful run still
replaces the complete destination with the exact v1.9.12 release contents.

## Install and run

Requirements: Windows 11 x64, at least 30 GiB free, and a connected staging
machine. Administrator rights are not required.

Use the pinned, checksum-authenticated bootstrap in the
[v1.9.12 README](https://github.com/Donovoi/bstrings/blob/v1.9.12/README.md#get-started).
It authenticates and replaces any existing physical installer file before
launching the authenticated v1.9.12 quality installer. The authenticated release
asset is `Install-BstringsQuality.ps1`.

Then run:

```powershell
.\bstrings-quality\bstrings.exe bundle verify
.\bstrings-quality\bstrings.exe analyze -d D:\evidence --full -o D:\results\case-01
```

The command reports measured percentage completion. A completed result has exit
code 0, `run.json` and `summary.json` status `complete`, and no `.incomplete`
marker.
