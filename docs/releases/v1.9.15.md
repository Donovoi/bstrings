# bstrings v1.9.15 - Windows x64

v1.9.15 is the complete Windows x64 quality/offline release. It improves the
measured C# language-triage bottleneck while preserving the single Full
profile, forensic provenance, deterministic report ordering, persistent
verified installer cache, and fresh atomic destination replacement.

## What changed

- successful Lingua results for ordinally identical eligible text are reused
  only inside the existing 2,048-record/8 MiB batch;
- unsuccessful detections still retry per record, injected detectors retain
  baseline behavior unless a test explicitly opts in, and no evidence cache
  survives a batch;
- raw detector values still drive every confidence/margin gate and translation
  decision, while the five reported score fields use deterministic 12-decimal
  round-to-even serialization;
- language-assessment rows now declare `scoreDecimalPlaces` and explicit raw
  `confidenceGatePassed`/`marginGatePassed` outcomes;
- the new synthetic benchmark requires exact assessment/candidate hashes and
  records wall time, allocation, GC, and working-set evidence; and
- Native AOT, additional raw Windows P/Invoke, and suppressed GC transitions
  were reviewed but not promoted because they did not clear Full-profile
  compatibility or measured-bottleneck gates.

Seven alternating pairs over 100,000 records reduced median triage time by
45.9% in accurate mode and 47.7% in fast mode at 50% batch-local duplication.
All-unique time changed by no more than 0.42%, and a one-million-record accurate
pair improved by 44.9%. Every accepted pair produced byte-identical candidate
and assessment outputs. These synthetic stage results are not a universal Full
analysis speed promise; improvement depends on exact eligible duplicates in
each bounded batch.

## Install and run

Requirements: Windows 11 x64, at least 30 GiB free, and a connected staging
machine. Administrator rights are not required.

Use the pinned, checksum-authenticated bootstrap in the
[v1.9.15 README](https://github.com/Donovoi/bstrings/blob/v1.9.15/README.md#get-started).
It authenticates the immutable release and installer digest before launching
`Install-BstringsQuality.ps1`. The installer assembles and verifies a fresh
sibling directory, atomically replaces an existing physical
`bstrings-quality`, and reuses an unchanged cached pack only after fully
checking its current expected length and SHA-256.

Then run:

```powershell
.\bstrings-quality\bstrings.exe bundle verify
.\bstrings-quality\bstrings.exe analyze -d D:\evidence --full -o D:\results\case-01
```

Installer and analysis commands report percentage completion. A completed
analysis has exit code 0, `run.json` and `summary.json` status `complete`, and
no `.incomplete` marker.
