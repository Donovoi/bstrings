# bstrings v1.9.2

v1.9.2 fixes the one-go Windows installer on hosts where profile-free Windows
PowerShell cannot resolve `Get-FileHash`. The README bootstrap and installer
now calculate SHA-256 directly through the built-in .NET cryptography API, so
download verification does not depend on PowerShell module auto-loading.

The release retains the complete quality kit introduced in v1.9.1: the
scanner, [Magika](https://github.com/google/magika),
[FLOSS](https://github.com/mandiant/flare-floss), OCR, language detection,
local translation, every built-in pattern, and provenance reporting without a
separate Python or package-manager installation.

## Install the quality kit

Requirements: Windows 11 x64, at least 30 GiB free, and a connected staging
machine. Administrator rights are not required. Follow the
[safe pinned installer flow](https://github.com/Donovoi/bstrings/blob/v1.9.2/README.md#get-started)
from the parent directory where you want `.\bstrings-quality`.

That flow queries GitHub's exact-tag API, rejects a draft or prerelease,
downloads `Install-BstringsQuality.ps1`, verifies its published API SHA-256,
and only then invokes `powershell.exe -File`. The installer independently
cross-checks the release checksum list before acquiring the kit. No web
response is piped into `Invoke-Expression`.

The installer is quality-only. It validates canonical release URLs, GitHub API
sizes and SHA-256 digests, the core and quality trust manifest, every acquired
pack, and the finished bundle. It makes up to three resumable attempts and
removes its versioned cache only after success; failed cache state is retained
for a safe retry.

## Verify and analyze

```powershell
.\bstrings-quality\bstrings.exe bundle verify
.\bstrings-quality\bstrings.exe analyze -d D:\carved --full -o D:\results\full
```

Copy the complete `bstrings-quality` directory to the air-gapped workstation
and run `bundle verify` again before evidence work. The analysis pipeline makes
no network request.

## Known boundaries

- `--full` does not mount filesystems or carve files from raw disk or memory
  images. Mount or carve first when filesystem-aware coverage is required.
- OCR, language detection, and translation are probabilistic. Confirm important
  leads against original evidence and untranslated records.
- DirectML requires a compatible host driver. CUDA is not included in the
  standard kit, and CPU remains the fallback.
- The installer requires a new destination and a connected staging machine.
  The assembled kit itself runs offline.
- Checksums and manifests establish byte consistency, not publisher identity.
  Authenticate the GitHub release through your normal trusted process. This
  release is not described as Authenticode-signed.
- Public Releases contain product, installation, checksum, license, manifest,
  and verification assets—not raw benchmark or case evidence.

See the [air-gapped deployment guide](https://github.com/Donovoi/bstrings/blob/v1.9.2/docs/air-gapped-deployment.md)
for transfer, verification, hardware, and operational details.
