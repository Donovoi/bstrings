# bstrings v1.9.4

v1.9.4 is a Windows x64 core release containing the backend crossover and
forensic-reporting work merged after v1.9.2. It adds measured CPU/GPU backend
selection diagnostics, expanded tab-separated match provenance, per-pattern
histograms, and additional forensic patterns for credentials, tokens, PII,
browser artifacts, and registry-analysis leads. The current catalog contains
66 built-in patterns.

## Use the core report workflow

Keep all extracted files together. To search an evidence file with every
current pattern and create the integrated report set:

```powershell
.\bstrings.exe analyze -f D:\evidence\memory.raw `
  -o D:\results\memory-strings `
  --recover-executable-strings off --ocr off --translation off `
  --lr all --processor auto
```

This produces the authoritative JSONL records plus `findings.tsv`,
`pattern-histogram.tsv`, `feature-histogram.tsv`, and
`pattern-histogram.html`. The output directory must be new or empty.

## Feature boundary

This core ZIP does not contain FLOSS, Magika, OCR runtimes/models, or local
translation assets. Consequently, `analyze --full` is not supported by this
package alone. The larger quality/offline kit remains on its separately gated
v1.9.2 channel and predates the v1.9.4 reporting, pattern, and backend changes.
Do not combine the versions. No published bundle currently provides both sets
of features in one run.

Treat extracted credentials and identity data as sensitive forensic evidence.
OCR, decoding, translation, registry interpretation, and pattern matches are
investigative leads that should be confirmed against the original evidence.
