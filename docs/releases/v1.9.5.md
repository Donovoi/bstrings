# bstrings v1.9.5

v1.9.5 is an immutable Windows x64 core-only release. It contains the tested
self-contained scanner and its checksum, including the v1.9.4 backend,
forensic-reporting, histogram, and 66-pattern work plus the v1.9.5
documentation and installer-pin preparation.

The complete offline build and all quality, balanced, and compact profile
acceptance gates passed, but GitHub correctly blocked adding those assets after
the preliminary core release had already been published under the repository's
immutable-release policy. Published immutable releases cannot accept new or
replacement assets, so v1.9.5 remains core-only rather than being retargeted or
silently altered.

Use v1.9.6 or newer for the complete quality/offline installer, FLOSS, Magika,
OCR/PDF, language assessment, and local translation bundle. The v1.9.5 core ZIP
can still produce native TSV findings and histograms:

```powershell
.\bstrings.exe analyze -f D:\evidence\sample.bin --lr all -o D:\results\core
```
