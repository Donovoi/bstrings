# bstrings v1.9.5

v1.9.5 is the complete Windows x64 quality/offline release. It combines the
v1.9.4 backend crossover and forensic-reporting work with the version-matched
FLOSS, Magika, OCR, language-detection, and local-translation bundle in one
verified installation path.

The release includes measured CPU/GPU/hybrid extraction selection, expanded
tab-separated match provenance, per-pattern and per-feature histograms, a
self-contained HTML visualization, and 66 built-in patterns covering PII,
credentials, structurally validated JWT candidates, browser artifacts,
high-value Registry paths, and crypto address families.

## Install the complete kit

Requirements: Windows 11 x64, a connected staging machine, and at least 30 GiB
free. Administrator rights are not required.

Use the
[safe pinned installer flow](https://github.com/Donovoi/bstrings/blob/v1.9.5/README.md#get-started).
It authenticates and downloads `Install-BstringsQuality.ps1`, then acquires,
assembles, and verifies every required runtime, model, tool, licence, and
manifest. The published `SHA256SUMS.txt` covers every public release asset.

After installation:

```powershell
.\bstrings-quality\bstrings.exe bundle verify
.\bstrings-quality\bstrings.exe analyze -d D:\carved --full -o D:\results\full
```

The completed analysis retains the authoritative JSONL evidence graph and also
writes `findings.tsv`, `pattern-histogram.tsv`, `feature-histogram.tsv`, and
`pattern-histogram.html` for filtering and visualization.

For an air-gapped examination, copy the complete verified
`bstrings-quality` directory to the disconnected workstation and run
`bundle verify` there again before case work.

## Boundaries

`--full` does not mount filesystems or carve files from raw disk or memory
images. Supply carved/mounted executables, documents, and images when FLOSS and
OCR coverage is required. A native scan can still search the raw bytes.

Treat extracted credentials and identity data as sensitive forensic evidence.
OCR, decoding, translation, browser/Registry classification, and pattern
matches are investigative leads that should be confirmed against the original
evidence.
