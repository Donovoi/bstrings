# bstrings v1.9.7

v1.9.7 is the corrected complete Windows x64 quality/offline release. It keeps
the v1.9.6 forensic reporting, 66-pattern catalogue, measured CPU/GPU/hybrid
selection, FLOSS, Magika, OCR/PDF, language assessment, and local translation
features while fixing an analysis-stopping translation edge case.

Identifier-only evidence such as `$SYNTH_TOKEN001` is now classified as
non-linguistic before language detection and translation. The bundled Python
adapter independently bypasses model inference for protected-identifier-only
records, while mixed natural-language text containing credentials, GUIDs,
tokens, URLs, paths, or other protected identifiers remains fail-closed if a
translation changes or removes the evidence identifier.

Long-running commands now expose measured percentage completion. Integrated
analysis reports overall stage progress plus byte- or record-level progress for
native extraction, language triage, translation eligibility, and offline
translation. The quality installer and its pack acquisition, bundle assembly,
and bundle verification operations report download, hashing, assembly, and
final verification percentages. Percentages describe completed work units;
they are not time estimates.

## Install the complete kit

Requirements: Windows 11 x64, a connected staging machine, and at least 30 GiB
free. Administrator rights are not required.

Use the
[safe pinned installer flow](https://github.com/Donovoi/bstrings/blob/v1.9.7/README.md#get-started).
It authenticates and downloads `Install-BstringsQuality.ps1`, then acquires,
assembles, and verifies every required runtime, model, tool, licence, and
manifest. The published `SHA256SUMS.txt` covers every public release asset.

After installation:

```powershell
.\bstrings-quality\bstrings.exe bundle verify
.\bstrings-quality\bstrings.exe analyze -d D:\carved --full -o D:\results\full
```

The completed analysis retains the authoritative JSONL evidence graph and also
writes `findings.tsv`, `pattern-histogram.tsv`, `feature-histogram.tsv`, and
`pattern-histogram.html` for filtering and visualization.

For an air-gapped examination, copy the complete verified
`bstrings-quality` directory to the disconnected workstation and run
`bundle verify` there again before case work.

## Boundaries

`--full` does not mount filesystems or carve files from raw disk or memory
images. Supply carved or mounted executables, documents, and images when FLOSS
and OCR coverage is required. A native scan can still search the raw bytes.

Treat extracted credentials and identity data as sensitive forensic evidence.
OCR, decoding, translation, browser or Registry classification, and pattern
matches are investigative leads that should be confirmed against the original
evidence.
