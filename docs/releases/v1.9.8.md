# bstrings v1.9.8

v1.9.8 is the complete Windows x64 quality/offline release focused on making
the installed interface and documentation easier to use without weakening the
v1.9.7 evidence, translation-safety, reporting, or progress guarantees.

## Easier terminal guidance

The executable now accepts conventional command-style help:

```powershell
.\bstrings.exe help
.\bstrings.exe help analyze
.\bstrings.exe help bundle verify
```

The root, analysis, and bundle help screens now explain which workflow to use,
show runnable examples, identify output requirements and completion markers,
describe percentage semantics, list pattern groups, and distinguish native
extraction, OCR, translation, and RAPIDS hardware controls. The native
`--processor auto` help displays the adaptive calibration threshold calculated
for the current host.

The integrated CLI now exposes the existing accepted translation adapter's
`--translation-strict-determinism` mode. It forces one request slot and
disables prompt-cache reuse for maximum repeatability on the same runtime, and
is rejected when parallelism is explicitly above one.

## Documentation and operator guidance

The new [terminal help and command reference](../command-reference.md) gives a
task-oriented command chooser, `--full` override examples, pattern/report
guidance, hardware boundaries, cancellation behavior, completion checks,
bundle operations, and the legacy flat-output route.

Installation guidance now has an explicit safe upgrade/retry procedure: install
the new version beside the old kit, verify it, and use a new results directory.
The enrichment and provenance guides document identifier-only translation
bypass, duplicate protected-token validation, strict determinism, and current
progress behavior. Current-version links and release-maintenance inventories
are aligned to v1.9.8.

## Retained forensic behavior

- Identifier-only values remain source evidence and bypass model inference.
- Mixed natural language containing protected identifiers remains fail-closed
  if translation changes, removes, or duplicates an identifier.
- Installer, bundle, extraction, and integrated workflows report measured
  percentage completion.
- Completed analysis writes the authoritative JSONL graph, `findings.tsv`,
  exact pattern/feature histograms, and the self-contained HTML chart.
- `--full` still does not mount filesystems or carve files from raw images.

## Install the complete kit

Use the
[safe pinned installer flow](https://github.com/Donovoi/bstrings/blob/v1.9.8/README.md#get-started),
then verify and inspect the local help:

```powershell
.\bstrings-quality\bstrings.exe --version
.\bstrings-quality\bstrings.exe bundle verify
.\bstrings-quality\bstrings.exe help analyze
```
