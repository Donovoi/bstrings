# bstrings v1.9.9 - Windows x64

This release fixes repeat installation from a directory that already contains
`Install-BstringsQuality.ps1`.

## Installer bootstrap replacement

The pinned README bootstrap now always replaces an existing physical installer
file after, and only after, the new download matches the exact published
v1.9.9 SHA-256 digest. It downloads to a unique sibling temporary file and uses
a same-directory replacement transaction. A download or authentication failure
leaves the previous installer untouched and removes the partial download.

This replacement applies to `Install-BstringsQuality.ps1`. Bundle safety remains
fail closed: a complete same-version `bstrings-quality` directory is reverified,
while an invalid, linked, or mixed-version destination is preserved rather than
patched in place.

The bootstrap behavior is covered on Windows PowerShell 5.1 and PowerShell 7,
including stale-file replacement, digest-mismatch preservation, temporary-file
cleanup, exact tag/URL checks, and launch ordering.

## Install the complete kit

Use the checksum-verifying bootstrap in the
[v1.9.9 README](https://github.com/Donovoi/bstrings/blob/v1.9.9/README.md#get-started).
It assembles and verifies the complete offline quality kit with native CPU,
Rust, CUDA/hybrid support, FLOSS, Magika, OCR, language detection, local
translation, all 66 patterns, TSV reports, and histograms.

After installation:

```powershell
.\bstrings-quality\bstrings.exe bundle verify
.\bstrings-quality\bstrings.exe help analyze
.\bstrings-quality\bstrings.exe analyze -f "C:\evidence\memory.raw" --full -o "C:\results\memory-full"
```

The result directory must be new or empty. Long operations report measured
percentage completion from 0% through 100%; percentages are completed work
units, not elapsed-time estimates.
