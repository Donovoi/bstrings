# bstrings v2.0.0 - Windows x64

v2.0.0 provides one complete Windows kit. It also uses shorter and clearer
public names.

## What changed

- The installer is `Install-Bstrings.ps1`.
- The default installation directory is `bstrings-kit`.
- The default verified cache is `.bstrings-installer-cache`.
- Release manifests and licenses use neutral names.
- The public base archive is an installer component, not a second product.
- The one-item translation model selector is removed.
- `--full` is now described as an analysis preset.
- Current documentation uses shorter, STE-inspired language.

The kit still contains native extraction, FLOSS, OCR, local translation,
decoding, patterns, reports, runtimes, models, and licenses.

## Upgrade

This release changes public installer and asset names. It is therefore a major
release.

The installer can migrate the verified v1.9.17 default installation. It builds
and verifies `bstrings-kit` before it removes the old path.

The installer can also reuse unchanged old cache objects. It checks each object
against the current size and SHA-256 before use.

The installer stops if both old and new default directories exist. It does not
replace an unrelated directory.

## Install and run

Requirements are Windows 11 x64 and at least 30 GiB of free space. Administrator
rights are not required.

Use the authenticated install command from the immutable v2.0.0 release page.
Then run:

```powershell
.\bstrings-kit\bstrings.exe bundle verify
.\bstrings-kit\bstrings.exe analyze -d D:\evidence --full -o D:\results\case-01
```

Success requires exit code 0 and two complete status files. The output must not
contain `.incomplete`.

Keep failed output for diagnosis. Use a new or empty output directory for the
next attempt.
