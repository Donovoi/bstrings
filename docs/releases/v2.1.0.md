# bstrings v2.1.0 - Windows x64

v2.1.0 can resume a supported incomplete analysis. It keeps the one complete
Windows kit and all existing analysis options.

## What changed

- `analyze -r -o <results>` resumes from the last verified whole stage.
- Resume checks the input, options, patterns, program, kit, and committed files.
- One process can write to a result directory at a time.
- Interrupted translation starts again unless its whole stage was committed.
- Progress shows reused and completed stages.
- A narrow importer supports the known incomplete v2.0.0 Full-analysis shape.

Resume is explicit. A normal analysis still needs a new or empty output
directory.

## Install or upgrade

Requirements are Windows 11 x64 and at least 30 GiB of free space. Administrator
rights are not required.

Use the authenticated install command from the immutable v2.1.0 release page.
The installer can upgrade an authenticated v2.0.0 kit. It verifies the new kit
before it replaces the old kit.

Then run:

```powershell
.\bstrings-kit\bstrings.exe bundle verify
.\bstrings-kit\bstrings.exe analyze -d D:\evidence --full -o D:\results\case-01
```

To resume a supported incomplete run, use:

```powershell
.\bstrings-kit\bstrings.exe analyze -r -o D:\results\case-01
```

Success requires exit code 0, complete `run.json` and `summary.json` files, and
no `.incomplete` marker. Keep failed output for diagnosis.

## Validation

The corrected five-pair benchmark passed. Median added new-run time was below
0.5 seconds. A long synthetic run reused 104.863 seconds of verified work and
saved 58.947 seconds. Canonical evidence parity and exact reused bytes passed.

The release gates also test every managed stage boundary, concurrent writers,
drift, malformed checkpoints, cancellation, and the single-file Windows build.
