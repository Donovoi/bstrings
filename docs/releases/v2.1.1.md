# bstrings v2.1.1 - Windows x64

v2.1.1 fixes resume validation for an incomplete analysis created by v2.0.0.
It also makes the user documentation shorter and more neutral.

## What changed

- The v2.0.0 resume importer validates native records against the saved v2.0.0
  extractor version.
- Current runs still validate native records against the current program
  version.
- The installer can upgrade a verified v2.1.0 kit.
- User documentation now describes program behavior without directing
  professional practice.

## Install or upgrade

Requirements are Windows 11 x64 and at least 30 GiB of free space. Administrator
rights are not required.

Use the authenticated install command from the immutable v2.1.1 release page.
The installer verifies the new kit before it replaces a verified older kit.

Then run:

```powershell
.\bstrings-kit\bstrings.exe bundle verify
.\bstrings-kit\bstrings.exe analyze -r -o D:\results\case-01
```

Resume validates the saved input, kit, options, patterns, and completed stage
files before it changes the output directory.

## Validation

The focused native and resume suites passed. The complete managed test suite
passed with only the existing platform-dependent symlink skips. A read-only
validation of the stopped v2.0.0 output passed all six import stages without
changing that directory.
