# bstrings v2.1.2 - Windows x64

Version 2.1.2 adds a narrow resume option for a stopped Full analysis that has
not committed translation output.

Use this command to continue with translation off:

```powershell
bstrings.exe analyze --resume -o D:\results\case-01 -e translation `
  --bundle-root D:\tools\bstrings-kit-2.1.1
```

The command checks the saved v2.1.1 run and source kit. It reuses validated
stages 1 through 6. It stores the old language-selection files as superseded
history, creates empty translation files, and continues with translation off.

The command accepts only the `translation` exclusion. It refuses the change if
translation or any later stage has a committed checkpoint.

This release also:

- records the source and derived resume generations;
- keeps inherited checkpoint and artifact identities;
- handles an interrupted generation change with a recovery journal;
- validates the v2.0 native lineage inside a v2.1.1 imported run; and
- fixes the repeated dash in resume option errors.

Validation completed with 1,112 passing .NET tests and four host link-capability
skips. PowerShell 5.1 and PowerShell 7 installer tests passed. The five-pair
24 GiB resume benchmark passed its overhead, reusable-work, saving, canonical
parity, and reused-checkpoint hash gates.

The Windows release contains one complete kit. Install it with the authenticated
command in the [README](../../README.md).
