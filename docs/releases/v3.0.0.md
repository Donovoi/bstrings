# bstrings v3.0.0 - Windows x64

Version 3.0.0 lowers pattern noise and makes the findings table easier to use.

This release changes the public `findings.tsv` header. It now has eight columns:

```text
PatternName	Match	Context	SourceFile	ArtifactType	Location	MatchStart	AttributesJson
```

`regex-matches.jsonl` keeps the complete pattern and provenance record.
`feature-histogram.tsv` groups equal pattern values and counts their occurrences.

The default pattern preset now selects 74 higher-confidence patterns. Eight
wider patterns remain available in the `candidates` group. Use this selector
for the complete catalog:

```powershell
--lr "all,candidates"
```

Base64 and email matching now use stricter default checks. Wider Base64, email,
MAC, IPv6, registry-root, ZIP-like, Solana-like, and Move-like values remain
available as named candidate patterns. The `pii`, `registry`, and `wallets`
groups retain their wider domain coverage.

Exact repeated record text can reuse bounded in-memory match descriptors. Each
reported occurrence still keeps its own source, location, context, and record
identity.

The v3.0.0 binary also retains the narrow translation-off resume path for an
exact stopped v2.1.1 Full run at stage 7. It verifies the saved v2.1.1 source
kit and creates a new v3.0.0 Off generation.

Local release validation passed 1,199 .NET tests, 497 Python tests, native Rust
tests, installer tests in PowerShell 5.1 and 7, and a packaged single-file
analysis smoke. Four .NET and three Python link tests skipped because this host
did not permit link creation.

The Windows release contains one complete kit. Install it with the authenticated
command in the [README](../../README.md).
